# Roger CV

王志飞（Roger）的互动个人简历作品。

包含机器人面罩动画、教育与实习经历、技能、联系方式和 PDF 简历。

## 下载与打开

1. 在仓库首页点击绿色 Code 按钮，选择 Download ZIP。
2. 解压下载的 ZIP 文件。
3. 使用 Microsoft Edge 或 Google Chrome 打开 index.html。
4. 向下滚动查看面罩动画及简历内容。

视频、图片和 PDF 等资源已内嵌在 index.html 中，下载后可以离线查看。推荐使用电脑浏览器。
